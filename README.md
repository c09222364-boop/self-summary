# 自用总结

这是一个面向 SillyTavern 的可视化数据编辑扩展，提供当前聊天的数据表格、模板结构、列定义和世界书注入位置编辑。

## 在酒馆中安装

1. 打开 SillyTavern 的 Extensions 面板。
2. 点击 Install Extension。
3. 粘贴仓库地址：`https://github.com/c09222364-boop/self-summary`
4. 安装后刷新酒馆。

## Userscript 兼容入口

如果使用 Tampermonkey 或 Violentmonkey，可以直接安装 [database-v.js](./database-v.js)。

## 3.6.3

- 打开或切换聊天、切换目标世界书后的首次同步，只清理当前目标书内本插件的临时表格，然后注入当前聊天数据。用户普通条目保留。
- 同一聊天、同一目标书后续保存只维护当前聊天条目，不重复清理其他聊天残留；同步失败后允许重试。
- 移除上一世界书位置追踪，不再因其他聊天的世界书改名或删除而阻断当前同步。

## 3.2.0

- 可为单张表启用“相对剧情时间”，并选择该表自己的时间列。
- 同步世界书时先检查最新 AI 楼层，没找到才逐层向前兜底，最多检查 5 层；识别以 `【2025年9月19日` 这类内容开头的剧情日期，其后的标点、时间和地点不限。
- 同一个 AI 楼层出现多个符合格式的日期时，采用 `<content>` 后的最后一个。
- 日期跨度采用结束日期，生成的“距当前剧情”列只存在于世界书临时投影中，不写入 checkpoint，也不调用 AI。
- 不监听 AI 回复；沿用聊天打开、聊天切换和手动保存时原本已有的世界书投影流程。
